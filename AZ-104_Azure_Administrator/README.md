# AZ-104 Azure Administrator Associate - Complete Study Guide

## Overview
The AZ-104 exam validates your ability to manage Azure identities, governance, storage, compute, virtual networking, and monitoring resources. This is an intermediate-level certification.

## Exam Details
- **Exam Code**: AZ-104
- **Duration**: 120 minutes
- **Number of Questions**: 40-60
- **Passing Score**: 700/1000
- **Cost**: $165 (varies by region)

## Exam Domains & Weightage

| Domain | Weight |
|--------|--------|
| Manage Azure identities and governance | 25-30% |
| Implement and manage storage | 15-20% |
| Deploy and manage Azure compute resources | 20-25% |
| Configure and manage virtual networking | 20-25% |
| Monitor and maintain Azure resources | 10-15% |

## Study Path

### Phase 1: Foundational Concepts (Week 1-2)
- Start with Azure fundamentals
- Understand ARM model and resource groups
- Learn about subscriptions and management groups

### Phase 2: Core Topics (Week 3-6)
- Study each domain in depth
- Use the module files for detailed content
- Complete hands-on labs in Azure portal

### Phase 3: Advanced Topics & Practice (Week 7-8)
- Deep dive into complex scenarios
- Review the cheat sheet
- Practice with sample questions

### Phase 4: Final Review (Week 9)
- Review weak areas
- Take full-length practice exams
- Study quick reference guides

## Tips for Success
✓ Hands-on experience is crucial - practice in Azure Portal/CLI/PowerShell
✓ Focus on ARM templates and Infrastructure as Code
✓ Understand RBAC and Azure Entra ID integration thoroughly
✓ Get comfortable with Azure CLI and PowerShell (newer Az modules recommended)
✓ Use Microsoft Graph PowerShell for modern identity management
✓ Understand managed identity vs service principals
✓ Practice troubleshooting scenarios
✓ Review Microsoft Learn modules for each topic
✓ Practice with Azure DevOps and CI/CD pipelines
✓ Join study groups and communities
