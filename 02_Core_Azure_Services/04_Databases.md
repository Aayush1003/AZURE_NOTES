# 🗄️ Database Services

Azure provides fully managed relational, NoSQL, and in-memory databases.

## 1. Azure SQL Database
- **What is it?** A fully managed relational database with auto-scale, integral intelligence, and robust security (PaaS based on SQL Server).
- **Benefits:** You don't need to manage the underlying OS or SQL Server instance. High availability, automated backups, and patching are built-in.

## 2. Azure Cosmos DB
- **What is it?** A globally distributed, multi-model NoSQL database service.
- **Features:** Single-digit millisecond response times, automatic scaling, SLA-backed 99.999% availability.
- **APIs Supported:** SQL API (Core), MongoDB API, Cassandra API, Gremlin API (Graphs), Table API.
- **Use Cases:** IoT, gaming, retail, real-time analytics where low latency globally is required.

## 3. Azure Database for PostgreSQL / MySQL / MariaDB
- **What is it?** Fully managed open-source relational database services.
- **Benefits:** Provides community editions of these databases with built-in high availability and dynamic scaling.

## 4. Azure Cache for Redis
- **What is it?** A fully managed, in-memory data store based on the open-source Redis software.
- **Use Cases:** Improves the performance and scalability of an application heavily dependent on backend data stores by caching frequently accessed data (e.g., session state, database query results).
