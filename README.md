# Azure Notes & Certification Guide ☁️

Welcome to the **Azure Notes** repository! This repository is designed to be a comprehensive guide and quick-reference cheat sheet for Microsoft Azure. Whether you are preparing for **AZ-900 (Azure Fundamentals)**, **AZ-104 (Azure Administrator)**, or looking to brush up on cloud concepts for an interview, you'll find structured notes here.

## 🗂️ Directory Structure

1. **[01_Cloud_Concepts](./01_Cloud_Concepts/README.md)**: Cloud computing basics, deployment models, IaaS vs PaaS vs SaaS.
2. **[02_Core_Azure_Services](./02_Core_Azure_Services/README.md)**: Compute (VMs, AKS), Networking (VNet, App Gateway), Storage (Blob, File), and Databases (Cosmos DB, Azure SQL).
3. **[03_Security_Identity_Compliance](./03_Security_Identity_Compliance/README.md)**: Microsoft Entra ID (Azure AD), RBAC, Network Security Groups (NSG).
4. **[04_Pricing_And_Support](./04_Pricing_And_Support/README.md)**: TCO Calculator, Cost Management, SLAs.
5. **[Fundamental](./Fundamental/)**: Hand-written notes and PDF references for AZ-900 and AZ-104.

## 🎯 Quick Tips for Azure Certifications
- **AZ-900**: Focus heavily on conceptual knowledge. Understand the difference between high availability, scalability, and elasticity. Know the basic services (App Service vs VMs, Cosmos DB vs Azure SQL).
- **AZ-104**: Focus on implementation, PowerShell/CLI commands, VNet peering, NSGs, and precise RBAC roles.
