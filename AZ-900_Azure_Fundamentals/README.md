# AZ-900 Azure Fundamentals - Complete Study Guide

## Overview
The AZ-900 exam validates your foundational knowledge of Azure cloud services, including compute, networking, storage, databases, and management. This is a beginner-level certification and prerequisite for other Azure certifications.

## Exam Details
- **Exam Code**: AZ-900
- **Duration**: 85 minutes
- **Number of Questions**: 40-60
- **Passing Score**: 700/1000
- **Cost**: $99 (varies by region)
- **Prerequisites**: None

## Exam Domains & Weightage

| Domain | Weight |
|--------|--------|
| Cloud concepts | 25-30% |
| Azure services | 60-65% |
| Azure pricing, SLAs, and lifecycle | 10-15% |

## Study Path

### Phase 1: Cloud Fundamentals (Week 1-2)
- Understand cloud computing models
- Learn Azure benefits and principles
- Study cloud service types (IaaS, PaaS, SaaS)

### Phase 2: Azure Services (Week 3-5)
- Study compute, storage, networking services
- Learn databases and data analytics
- Understand management and governance

### Phase 3: Pricing & Support (Week 6)
- Review pricing models
- Understand SLAs and support
- Study lifecycle and compliance

### Phase 4: Final Review (Week 7)
- Review weak areas
- Take practice exams
- Study quick reference guides

## Tips for Success
✓ Focus on concepts, not technical details
✓ Understand cloud benefits and trade-offs
✓ Learn service capabilities and use cases
✓ Know the difference between similar services
✓ Understand pricing and SLAs
✓ Review compliance and security features
✓ Practice with sample questions
✓ Take full-length practice exams
