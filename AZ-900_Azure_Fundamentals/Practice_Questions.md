# AZ-900 Practice Questions & Sample Answers

## Cloud Concepts (8 Questions)

### Question 1\n**Scenario**: A company wants to migrate from on-premises servers to the cloud. They want to pay only for computing power they use and avoid upfront hardware investments.\n\n**Which cloud advantage is this?**\nA) Reliability\nB) Scalability\nC) Cost optimization\nD) Performance\n\n**Answer**: C) Cost optimization\n\n**Explanation**: Moving from CapEx to OpEx (no upfront investment, pay-as-you-go) is cost optimization. Reliability is uptime. Scalability is adjusting resources. Performance is speed.\n\n---\n\n### Question 2\n**Scenario**: A company needs a development/testing environment that can be deleted and recreated quickly. Cost is the primary concern.\n\n**Which cloud service model is best?**\nA) SaaS\nB) PaaS\nC) IaaS\nD) On-premises\n\n**Answer**: C) IaaS\n\n**Explanation**: IaaS (VMs) is cheapest for dev/test and easy to delete. PaaS has more overhead. SaaS is for end-user applications. On-premises defeats the purpose.\n\n---\n\n### Question 3\n**Scenario**: A retailer opens a new office in Australia. They want to serve users there with low latency without setting up local infrastructure.\n\n**Which cloud benefit applies?**\nA) Disaster recovery\nB) Global reach\nC) Security\nD) Cost savings\n\n**Answer**: B) Global reach\n\n**Explanation**: Deploying in Azure's Australian region provides global reach. Disaster recovery is for failover. Security is separate benefit. Cost is incidental.\n\n---\n\n### Question 4\n**Scenario**: A company has applications in Azure and on-premises data center. They need secure communication between both.\n\n**What should they implement?**\nA) Public internet connection\nB) VPN Gateway or Express Route\nC) Increase firewall rules\nD) Peer networks\n\n**Answer**: B) VPN Gateway or Express Route\n\n**Explanation**: VPN/ER provide secure tunnels. Public internet is insecure. Firewall rules don't create connection. Peering is for VNets only.\n\n---\n\n### Question 5\n**Scenario**: A company needs to ensure applications remain available if an Azure region goes down.\n\n**What should they use?**\nA) Availability Zones\nB) Availability Sets\nC) Multi-region deployment\nD) Single region redundancy\n\n**Answer**: C) Multi-region deployment\n\n**Explanation**: Multi-region protects from region outage. Zones (within region) and Sets (within zone) don't protect from region failure.\n\n---\n\n### Question 6\n**Scenario**: A development team wants to deploy a web app for testing. They need minimal upfront cost and quick setup.\n\n**What should they use?**\nA) Dedicated servers\nB) Azure free tier or pay-as-you-go\nC) Reserved instances for 3 years\nD) Spot instances\n\n**Answer**: B) Azure free tier or pay-as-you-go\n\n**Explanation**: Free tier allows testing without cost. Pay-as-you-go is flexible. Reserved instances lock into 3 years. Spot instances can be interrupted.\n\n---\n\n### Question 7\n**Scenario**: A company's application must comply with GDPR (data must remain in EU). They're considering Azure.\n\n**Can Azure support this?**\nA) No, Azure data goes to US\nB) Yes, deploy in EU regions\nC) Only with additional encryption\nD) Yes, but costs extra\n\n**Answer**: B) Yes, deploy in EU regions\n\n**Explanation**: Azure has EU regions that ensure data residency. No extra cost. GDPR compliance possible in EU.\n\n---\n\n### Question 8\n**Scenario**: A company wants a service where they manage everything (OS, application, database). They need full control.\n\n**Which service model?**\nA) SaaS\nB) PaaS\nC) IaaS\nD) On-premises only\n\n**Answer**: C) IaaS\n\n**Explanation**: IaaS (VMs) provides maximum control. PaaS and SaaS have managed components. On-premises isn't cloud.\n\n---\n\n## Azure Services (8 Questions)\n\n### Question 9\n**Scenario**: A company needs a fully managed relational database for their web application. They don't want to manage updates or backups.\n\n**What should they use?**\nA) SQL Server on VM\nB) Azure SQL Database\nC) Azure Cosmos DB\nD) Azure Storage Tables\n\n**Answer**: B) Azure SQL Database\n\n**Explanation**: SQL Database is managed (backups, patching automatic). VM requires manual management. Cosmos DB is NoSQL. Tables isn't relational.\n\n---\n\n### Question 10\n**Scenario**: A company needs to store photos and videos. The data is accessed infrequently but must be retained for 7 years for compliance.\n\n**What's the best storage option?**\nA) Hot tier\nB) Cool tier\nC) Archive tier\nD) Premium blob\n\n**Answer**: C) Archive tier\n\n**Explanation**: Archive tier is lowest cost for infrequent access. Hot/Cool tiers cost more. Archive fits 7-year retention requirement.\n\n---\n\n### Question 11\n**Scenario**: A healthcare provider needs to run medical imaging analysis that's compute-intensive. It runs only during off-peak hours.\n\n**Which is most cost-effective?**\nA) Always-on VMs\nB) Batch processing with Spot instances\nC) Reserved instances\nD) Pay-as-you-go VMs\n\n**Answer**: B) Batch processing with Spot instances\n\n**Explanation**: Batch + Spot instances save up to 90% for off-peak workloads. Always-on wastes resources. Reserved instances require upfront commitment.\n\n---\n\n### Question 12\n**Scenario**: A startup needs a serverless solution for handling API requests that vary dramatically throughout the day.\n\n**What should they use?**\nA) App Service with Basic plan\nB) Virtual Machines\nC) Azure Functions\nD) Azure Container Instances\n\n**Answer**: C) Azure Functions\n\n**Explanation**: Functions scale automatically and charged per execution. App Service Basic doesn't auto-scale. VMs require management. ACI doesn't auto-scale.\n\n---\n\n### Question 13\n**Scenario**: A company uploads large volumes of files that need to be distributed globally to users with low latency.\n\n**What should they combine?**\nA) Blob Storage alone\nB) Blob Storage + Azure CDN\nC) Virtual Machines\nD) App Service\n\n**Answer**: B) Blob Storage + Azure CDN\n\n**Explanation**: CDN caches content globally for low latency. Storage alone doesn't provide edge locations. VMs/App Service aren't optimal for file distribution.\n\n---\n\n### Question 14\n**Scenario**: A company needs 99.99% SLA for their application with VMs. What's needed?\n\nA) Single VM with backups\nB) 2 VMs in same Availability Zone\nC) 2+ VMs in different Availability Zones\nD) 2 VMs in different regions\n\n**Answer**: C) 2+ VMs in different Availability Zones\n\n**Explanation**: Availability Zones provide 99.99% SLA. Single VM = 99.9%. Same AZ doesn't help. Different regions is overkill.\n\n---\n\n### Question 15\n**Scenario**: A company needs to manage resources, apply policies, and track spending across multiple subscriptions.\n\n**What Azure feature helps?**\nA) Resource Groups\nB) Management Groups\nC) Subscriptions\nD) Resource tags\n\n**Answer**: B) Management Groups\n\n**Explanation**: Management Groups organize subscriptions hierarchically and apply policies. Resource Groups are within subscription. Tags help organization, not policy.\n\n---\n\n## Pricing & Support (4 Questions)\n\n### Question 16\n**Scenario**: A company commits to using Azure VMs for the next 3 years. They want maximum savings.\n\n**What pricing option?**\nA) Pay-as-you-go\nB) 1-year reserved instance\nC) 3-year reserved instance\nD) Spot pricing\n\n**Answer**: C) 3-year reserved instance\n\n**Explanation**: 3-year commitment saves 40-50%. 1-year saves ~30%. Pay-as-you-go costs most. Spot can be interrupted.\n\n---\n\n### Question 17\n**Scenario**: A company's SLA requirement is 99.95% uptime.\n\n**How much downtime is acceptable per year?**\nA) 3.65 days\nB) 4.38 hours\nC) 52.6 minutes\nD) 1 hour\n\n**Answer**: B) 4.38 hours\n\n**Explanation**: 99.95% = 4.38 hours/year downtime. 99.9% = 8.76 hours. 99.99% = 52.6 minutes.\n\n---\n\n### Question 18\n**Scenario**: A company needs 24/7 technical support with < 1 hour response time for production issues.\n\n**Which support plan?**\nA) Free support\nB) Developer support\nC) Standard support\nD) Professional Direct support\n\n**Answer**: C) Standard support\n\n**Explanation**: Standard provides <1h response for critical issues. Developer is < 24h. Professional Direct provides <15min. Free has no SLA.\n\n---\n\n### Question 19\n**Scenario**: An organization wants to ensure compliance with HIPAA (healthcare) and PCI-DSS (payment cards).\n\n**Does Azure support this?**\nA) No, Azure can't be HIPAA/PCI compliant\nB) Yes, with additional fees\nC) Yes, Azure offers compliance certifications\nD) Only HIPAA, not PCI-DSS\n\n**Answer**: C) Yes, Azure offers compliance certifications\n\n**Explanation**: Azure meets both HIPAA and PCI-DSS standards. No additional fees.
